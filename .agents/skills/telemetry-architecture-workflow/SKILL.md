# Telemetry Architecture Workflow

If you are tasked with adding, modifying, or debugging telemetry and analytics, you MUST read the canonical telemetry architecture document before proceeding:

1. Read the canonical document using `view_file` on `docs/docs/guidelines/telemetry-architecture.md`.
2. Adhere strictly to the "Privacy First" opt-in tracking model described there.
3. Ensure that new events follow the unified event taxonomy.
