# Diabetic Ketoacidosis

## Diagnostic Criteria

1. Diabetic: Plasma glucose > 200 mg/dL
2. Ketosis: Serum beta-hydroxybutyrate > 3.0 mmol/L or urine ketone 2+
3. Acidosis: arterial pH < 7.3 or HCO3 < 18 mmol/L
