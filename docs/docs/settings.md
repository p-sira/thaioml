# Settings & Preferences

Customize your reading experience on ThaiOML. Your preferences are saved locally to your device.

## Accent Color

Select an accent color for interactive elements like links and buttons. The default is neutral gray.

<div id="accent-color-picker"></div>

## Theme Mode

You can toggle between the Leuko (Light) and Darkroom (Dark) monochrome modes using the button in the top navigation bar.
